Spiritual Well

Unity · C# · 2D 多角色平台解谜 · 团队项目

一款 Unity C# 开发的 2D 多角色协作解谜游戏，玩家需要在战士、盗贼、法师和弓箭手之间切换，利用角色专属能力破解机关、探索关卡并推进剧情。

角色能力关卡交互ScriptableObject队伍 UI

我的职责

  • 负责战士、盗贼、法师和弓箭手的核心能力开发。
  • 实现角色切换、队伍控制及镜头跟随逻辑。
  • 负责角色能力与风场、平台、箭矢按钮、陷阱等关卡机关的交互。
  • 负责角色死亡、复活、检查点传送和关卡流程。
  • 实现对话触发、角色招募、暂停菜单、地图及队伍信息 UI。
  • 使用 ScriptableObject 管理角色、队伍和对话数据。
