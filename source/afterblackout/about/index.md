# AfterBlackout

## 一句话简介

AfterBlackout 是一款支持多人联机的合作型僵尸生存游戏。

## 玩法

玩家需要与其他玩家组队，在僵尸袭击中探索地图、收集资源、启动发电机并完成撤离目标。

## 平台

- Windows PC
- 使用 Unreal Engine 5 开发
